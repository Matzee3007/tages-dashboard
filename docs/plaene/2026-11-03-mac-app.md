# Plan: Mac-App mit Tauri

**Ziel:** Eine selbst gebaute Mac-App „Heute“ zeigt die Vercel-Adresse in einem eigenen Fenster und hat ein Symbol in der
Menüleiste, über das sich das Fenster holen und ausblenden lässt.

**Vorgehen:** Tauri kommt als kleine Hülle in den Ordner `src-tauri/`. Die Website bleibt unverändert, die Hülle lädt nur ihre
Adresse. Die einzige eigene Logik (was ein Linksklick tut) ist als reine Funktion getestet, der Rest wird am echten Mac geprüft.

**Technik:** Tauri 2 (`tauri` 2.12, `@tauri-apps/cli` 2.12), Rust über `rustup`, `sips` von macOS für die PNG-Dateien.

**Anforderung:** [[projects/tages-dashboard/docs/Projektvision|Projektvision]], Fahrplan Phase 1, Schritt 4, und
[[projects/tages-dashboard/docs/adr/0003-mac-app-mit-tauri|ADR 0003]]. Freigabe des Mocks am 2026-11-03: Symbol a, Verhalten B.

## Feste Vorgaben

- Branch `feature/mac-app`, ein PR für Plan und Code, vor dem Merge `/code-review` und Agent `plan-pruefer`.
- Adresse `https://tages-dashboard-iota.vercel.app` als `build.frontendDist` und `build.devUrl`, keine Dateien der Website in der
  App.
- Name „Heute“, Kennung `com.matzee3007.heute`, Fenster-Label `main`, Fenster 1200 × 800.
- Nur `.app` bauen (`bundle.targets: ["app"]`), ad-hoc signiert (`bundle.macOS.signingIdentity: "-"`), ohne Apple Developer
  Program und ohne Weitergabe.
- Menüleiste: Symbol als Template-Bild (`icon_as_template(true)`), `show_menu_on_left_click(false)`. Menü: „Heute öffnen“
  (`oeffnen`), „Neu laden“ (`neu_laden`), Trennlinie, „Beenden“ (`beenden`).
- Linksklick: Fenster sichtbar und im Fokus → ausblenden, sonst nach vorn holen. Roter Knopf: nur ausblenden, die App läuft
  weiter.
- Die Website bekommt keine Rechte in der Hülle: keine `remote`-Angabe in einer Capability (Rechte-Datei von Tauri), keine
  eigenen Tauri-Befehle, `withGlobalTauri` bleibt aus.
- Keine Plugins. Website, Proxy und Login bleiben unverändert.
- Die CI bekommt keinen Rust-Schritt: Sie läuft auf Linux, die Hülle ist nur für den Mac. `cargo test` läuft lokal.
- Vor jedem Commit `npm run check`. Commit-Nachrichten englisch, im Imperativ, mit Co-Authored-By-Zeile.

## Prüf-Schwerpunkte

1. App beenden und neu starten, am nächsten Tag noch einmal → weiterhin angemeldet → Aufgabe 5, Prüfung 3.
2. Roter Knopf, danach Klick auf das Dock-Symbol → Fenster kommt wieder, nichts wirkt abgestürzt → Aufgabe 4, Schritt 4.
3. Fenster minimiert, dann Linksklick auf das Menüleisten-Symbol → Fenster kommt nach vorn, nicht „nichts passiert“ →
   Aufgabe 3, Test `minimiert_oder_hinten_kommt_nach_vorn` und Schritt 6.
4. App ohne Internet starten → Fehlerseite statt Absturz, Menüleiste geht, nach „Neu laden“ mit Internet ist die Seite da →
   Aufgabe 5, Prüfung 5.
5. Doppelklick auf die `.app` nach dem Kopieren nach `/Applications` → startet ohne Bezahlkonto, höchstens mit einer einmaligen
   Freigabe in den Systemeinstellungen → Aufgabe 5, Prüfung 1.

36 × 36 px (18 pt doppelt), vier schwarze Kacheln auf durchsichtigem Grund, je 16 px groß, 4 px Abstand, wie Variante a des Mocks.
Farbe egal, macOS nutzt nur die Form.

- [x] **Schritt 2: `assets/icons/mac-app.svg` anlegen**
