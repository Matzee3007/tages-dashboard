# Tages-Dashboard

Persönliches Live-Dashboard als Web-App (PWA) nur für mich: Sport, Schritte und KI-News auf einen Blick, auf Mac, iPhone und iPad.

Entstanden mit `/projekt-starten` aus dem [claude-ecosystem](https://github.com/Matzee3007/claude-ecosystem)
am 2026-10-24.

## Loslegen

Live: https://tages-dashboard-iota.vercel.app

```bash
cd ~/claude-ecosystem/projects/tages-dashboard
claude
npm ci
npm run dev   # http://localhost:3000
```
